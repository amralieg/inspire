# Inspire requirements ledger

Single source of truth for every Inspire ask. The coordinator keeps the working copy outside the repo. This file is published from it by `app/scripts/ledger_publish.py`, which sanitizes every row. Do not edit this file by hand: change the working copy and re-run the publisher.

## How the ledger works

- Every ask becomes a REQ row before any work starts. A duplicate ask links to the existing REQ.
- A REQ is DONE only when its code is on the integration branch (SHA), its tests are green, and it was walked live on an installed build.
- A release candidate is cut only when every in-scope REQ is DONE.
- Every builder brief names the REQ ids it owns and reports per REQ.
- States: OPEN (not started), BUILDING (lane and worktree), LOCAL (on a branch, tests green, not on the integration branch), DEV (on the integration branch, not live-walked), DONE (live-walked in an rc), BLOCKED (named blocker), OUT, SUPERSEDED.
- Release column: RC2 = in v1.5.3-rc.2 scope; HANDOFF = left for the next person; not in RC2 scope = DONE, SUPERSEDED or OUT, state kept as recorded.
